# Verification and Sanity Checks

## 1. Shape conventions (global)
The manuscript mixes conventions (`T` vs `T^T`). This repository enforces the following:

- Data matrices:
  - `A ∈ R^{m×k}` (FM features)
  - `B ∈ R^{m×l}` (MM features)

- Transition operator:
  - `T ∈ R^{l×k}` maps a feature vector `a(x) ∈ R^k` to `b*(x) ∈ R^l` by
    `b*(x) = T a(x)`.
  - At matrix level this is `B* = A T^T`.

- For convenience, we also use `W = T^T ∈ R^{k×l}`, so that `B* = A W`.

All code asserts dimension consistency at runtime and logs shapes for every run.

## 2. Algorithmic sanity checks
### 2.1. Synthetic (Section 3.4)
- **Generator estimation (Algorithm 2)**
  - MDS to 2D uses fixed `random_state`.
  - Decoder is linear regression from 2D back to the original feature space.
  - A single global rotation is applied to the full point cloud, consistent with the manuscript.
  - Generator is recovered via a pseudoinverse least squares solve.

- **Transition matrix solve (Algorithm 1)**
  - The combined system is explicitly constructed using Kronecker products.
  - The solution uses an SVD-based pseudoinverse with truncation `τ`.

- **Robustness test (Scenario 3)**
  - Rotated features are generated by the same 2D bridge used in Algorithm 2.
  - Targets in MM space are generated analogously (same rotation-and-decode procedure).

### 2.2. MNIST (Section 3.5)
- **Autograd generator estimation**
  - Rotations are implemented via `affine_grid` + `grid_sample`, so the pipeline can compute exact derivatives with respect to `θ`.
  - Derivatives are obtained via `torch.autograd.functional.jvp` (Jacobian-vector product) evaluated at `θ=0`.

- **SVD-grounded solves**
  - Baseline `T_old` uses an SVD-based pseudoinverse of the Gram matrix `(A^T A)`.
  - The equivariant solve uses LSQR on an implicit stacked operator corresponding to Algorithm 1’s vectorized system. LSQR is based on Golub–Kahan bidiagonalization and can be interpreted as constructing a Krylov approximation to the operator’s SVD.

## 3. Unit tests
Run:
```bash
python -m unittest -v
```
The `tests/test_synthetic.py` suite checks:
- correct interpretation of repeating decimals,
- shape consistency for synthetic inputs,
- correctness of the `λ=0` case in Algorithm 1.

## 4. Numerical stability logging
Each run logs:
- config and seed,
- matrix shapes,
- singular value spectra for SVD-based solves (synthetic) and Gram matrices (MNIST generators and baseline),
- LSQR diagnostics (MNIST equivariant solve): iteration count, estimated condition number, and residual norms.
